# 内容概要

	WebGL InputField插件能在WebGL平台下兼容谷歌、火狐浏览器全屏状态下中文输入


# 使用方法

  1. 给InputField替换ttf格式中文字体
  2. 给InputField挂载上 InputField_WebGL 脚本
  3. 全屏时调用 WebGLFullScreen.UnityFullScreen()
