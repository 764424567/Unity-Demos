# Changelog

## [1.0.0] - 2020-04-01
### Added

* 记录事件，数据持久化到本地，实现录像回放


## [1.0.1] - 2020-04-09
### Fixed

 * 功能重构: 修改ViedoHandler和EventBuffer，将事件的反序列化推迟到对应的关键帧当中
 * 功能添加：添加一个菜单Rainier->Reset UniqueID,用于场景中有些物体一开始就处于隐藏状态,或者有些物体粘贴复制，导致，UniqueID为-1，或者重复。重新初始化所有的ID使用

## [1.0.2] - 2020-05-14
### Fixed

 * bug修复: 在webgl下进行数据回放出现异常
 * 功能优化：优化数据存储，降低事件存储所占内存
 * 优化部分代码

## [1.0.3] - 2020-05-21
### Fixed

 * 功能优化：优化实验数据过大，请求实验回放数据并反序列的过程中，内存激增。导致程序短暂无响应的问题。
 * 优化部分代码

## [1.0.4] - 2020-06-01
### Fixed

 * bug修复: 在pc下数据保存异常

## [1.0.5] - 2020-10-23
### Fixed

 * bug修复: 多次保存，回放事件丢失问题，进度异常问题
 * 优化部分代码以及UI显示
